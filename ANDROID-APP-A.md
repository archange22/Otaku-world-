# Otaku-World Android app: Step A

This change prepares the web project for a basic Android wrapper using Capacitor.

## Included
- Capacitor core, Android platform package, and CLI dependencies in `package.json`
- Capacitor scripts: `android:add`, `cap:sync`, and `cap:open`
- App identity: `com.otakuworld.app` / `Otaku-World`

## Build steps
Run these commands from the repository root in a Node.js environment:

```sh
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

The Android project is generated by `npx cap add android`; it is not committed by this preparation step. Opening/building it normally requires Android Studio or a configured Android build environment.

## Important
- This is a preparation change, not a finished APK or Play Store release.
- Confirm the actual Vite/TanStack build output matches `webDir: "dist"` before syncing. If the app outputs client assets to a subdirectory, update `webDir` to that directory.
- Before public distribution, verify content distribution rights, privacy disclosures, age/content ratings, and Google Play policies.
